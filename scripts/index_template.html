prompt-injection-bench

33 hand-authored indirect prompt-injection attacks (10 techniques) and 20 benign/benign-adversarial documents, run against a real tool-using claude-sonnet-5 agent under 6 defenses. Every result below is a recorded replay of a real API run — no live calls happen on this page. Source →

Action-level hijack = the agent actually called send_email with attacker-controlled arguments the user never asked for — the metric this project treats as authoritative. Text-level = the doc's canary string appears anywhere in the agent's reply, a much weaker signal that also fires when the model merely quotes or discusses the attempt while explaining it refused. See the repo's README and COMPARISON.md for the full methodology and honest caveats.
